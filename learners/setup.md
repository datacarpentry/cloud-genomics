This workshop is designed to be run on pre-imaged Amazon Web Services
(AWS) instances. For information about how to
use the workshop materials, see the
[setup instructions](https://datacarpentry.github.io/genomics-workshop/#option-a-recommended-using-the-lessons-with-amazon-web-services-aws) on the main workshop page. The Cloud Genomics lesson requires no additional setup.
